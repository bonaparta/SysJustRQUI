## 先讀：流程改了

這一輪把 loop engineering 的規則改掉了，接手前務必讀 `AGENTS.md`「自主範圍」：

- **`ready` issue 一路做到 merge，中間不問**：開分支 → PR → `gh pr merge --auto --merge --delete-branch` → issue 留言 → 寫交接檔（也走 PR）。
- **只有四種情況要停**：改 repo 設定／權限、刪資料、規格缺漏、要改範圍。停的時候在 issue 留言（附選項與推薦）、加 `blocked`，去做下一張，**不要在對話裡等人**。
- **開工回報 3 句話後直接開工**，不等確認。
- **所有改動都走 PR，包括文件與交接檔**：`main` 有 ruleset `protect-main`，沒有 bypass，直推會被拒絕。純 `*.md`／`docs/` 變更 CI 會跳過編譯，很快綠燈。
- **一張 issue 盡量一個 PR**；PR 還沒 merge 時，後續改動直接加 commit 進同一個 PR。

## 做了什麼

- repo：`allow_auto_merge`、`delete_branch_on_merge` 開啟。
