## 前一輪記錄的架構與完成項目（歷史參考）

- CI：Windows + macOS，fmt／build／test／clippy。
- `main` ruleset `protect-main`：必須 PR、兩平台 required checks，不允許 bypass／force push／刪除。
- auto-merge 與 merge 後刪分支已開；所有變更（含文件與交接檔）走 PR，CI 綠燈由 agent 自己 merge。
- Cargo workspace：`app` → `ui`、`quote`；`quote` 為純資料模型，不依賴 UI；`ui` 不依賴 `quote`；另有獨立開發工具 `xtask`。
- `default-members` 保留 app／ui／quote，日常 `cargo run` 不受開發工具 binary 影響；檢查全部成員須用 `--workspace`，fmt 用 `--all`。
