### macOS 編譯的兩個解法（給使用者決定）

1. 使用者本人在終端機執行下面兩行，之後 `cargo build` 不加參數也能過：
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -license accept
   ```
2. 在 `Cargo.toml` 為 GPUI 開啟 `runtime_shaders`。好處是 Mac 不必裝完整 Xcode，壞處是 shader 改到啟動時編譯。正式包版應該用預先編好的 shader，所以這個選項比較適合開發階段。CI 的 macOS 機器有完整 Xcode，不受影響。
